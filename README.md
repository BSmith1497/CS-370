# CS-370
This is the final project I developed while in CS 370 and SNHU.


For this project, I worked on developing an intelligent pirate agent that used reinforcement learning to navigate a maze and find a treasure. I was provided starter code that included the maze environment, the experience replay functionality, and portions of the neural network used to train the agent. My responsibility was to complete the deep Q-learning algorithm that provided the training for trial and error for the agent. I worked on implementing the training process, including how the agent selected actions, stored experiences, and learned from rewards. One of the extra steps I took was adding a completion check. This check monitored the agent's win rate to ensure it could consistently achieve a 100% win rate before confirming the training was complete.
